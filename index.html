Ordnersystem

Sauber getrennt für GitHub Pages

Die Startseite liegt im Hauptordner. Einzelne Projekte liegen unter projects/, damit später weitere Homepages einfach ergänzt werden können. 

/
├── index.html
├── assets/
│   └── site.css
└── projects/
    ├── opv-original/
    │   └── index.html
    └── opv-professional/
        └── index.html

Warum diese Struktur?

GitHub Pages kann direkt aus dem Hauptbranch veröffentlichen. Die Index-Seite ist der Einstiegspunkt, die Projektordner enthalten die eigentlichen Websites.

Erweiterbar

Neue Projekte können später einfach als weiterer Unterordner in projects/ hinzugefügt und auf dieser Seite verlinkt werden.

Direkte Links

Jede Homepage kann direkt verlinkt werden, bleibt aber trotzdem über diese zentrale Übersicht erreichbar.
